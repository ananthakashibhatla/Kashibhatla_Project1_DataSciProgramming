## Project 1 - DataScience Programming Non-Majors EDA

The purpose of this project is to explore the data science questions and perspectives regarding the motivations, various factors and interest rate(to name a few) in taking 
a computing class as non-majors in the CS and DS world.

## 5 EDA questions answered in the Part 3 file 

1) Based on the non-majors survey dataset, how did motivation levels influence students
to take a computing course? 
2) What was the gender distribution of students as non-majors in the computing course? 
3) What is the race split between the non-computing students, ethnic groups of taking 
a computing course? 
4) What is the age split between the non-computing students, in terms of taking a 
computing course? 
5) Was there a scaling rate, from 1-5 between different critieria, gender and age only, in 
terms of interest rate, between the non-computing students taking a computing class? 

We will use the Python's data visualization libaries to answer these questions(see Part 3 file)

## Project 1 Files 

1. **Non-Majors Survey Results - Fall 2024.csv** - Raw, uncleaned original CSV survey file
2. **Non-Majors Survey Results - Fall 2024 Cleaned Version.csv** - Cleaned, filtered survey file from Part 2 EDA code
3. **Kashibhatla_Project1_Part2.ipynb** is the Jupyter notebook file that we used to primarily clean the raw, uncleaned original file into the cleaned CSV file 
4. **Kashibhatla_Project1_Part3.ipynb** is the Jupyter notebook file that we used to analyze the cleaned csv file from part 2 and answer our 5 data science EDA questions outlined above using bar graph visualization and statistical distributions.
